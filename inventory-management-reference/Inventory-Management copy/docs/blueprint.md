# **App Name**: StockPilot

## Core Features:

- Inventory Tracking: Track items, manage stock levels, and record consumption data.
- Purchase Order Management: Create, finalize, and manage purchase orders with dealer selection and price comparison.
- Delivery Verification: Upload timestamped photos of deliveries and bills, with price matching validation.
- Automated Notifications: Trigger alerts for low stock, approaching expiry dates, delayed deliveries, and price changes using a reasoning tool.
- Role-Based Access: Implement admin and staff roles with corresponding access permissions.
- Consumption and Lasting Time Calculation: Automatically calculate lasting time based on opening and end dates. Auto-decrease stock based on consumption logs.
- Reporting and Analytics: Generate summary dashboards for stock overview, monthly consumption, dealer performance, and expiring soon items.

## Style Guidelines:

- Primary color: Soft Blue (#89B4FA) for a calm and reliable feel.
- Background color: Light Blue (#F0F8FF), subtly desaturated and bright.
- Accent color: Purple (#A685E2) to highlight interactive elements and important notifications.
- Font pairing: 'Poppins' (sans-serif) for headlines and 'PT Sans' (sans-serif) for body text.
- Use clear, geometric icons representing inventory items, alerts, and reports.
- Clean and organized layout with clear separation of sections for easy navigation.
- Subtle animations for state transitions, such as loading and saving data, to provide visual feedback.
